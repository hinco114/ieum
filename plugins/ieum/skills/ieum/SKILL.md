---

이음 플러그인의 MCP 도구를 사용한다.

- 처음 설정할 때 사용자가 지정한 로컬 폴더를 `setup`에 절대 경로로 전달한다. 경로를 알려주지 않았다면 어디에 기억을 저장할지 묻는다.
- “이건 기억해”라고 하면 `remember`에 내용을 전달한다. 출처가 있으면 함께 남긴다. 저장 결과의 `sync`를 확인하고, push가 완료되지 않았으면 상태를 함께 알린다.
  - 사용자가 기억을 연결할 프로젝트를 지정하면 그 프로젝트명을 `project`에 전달한다.
  - 그 밖에는 대화 맥락에서 기억의 적용 범위를 판단한다. 특정 프로젝트에만 적용되는 설정이나 결정이면 해당 프로젝트명을 전달한다.
  - 여러 프로젝트에서 재사용할 기술 지식이나 팁, 적용 범위가 불분명한 기억은 `project`를 생략한다. 작업 중인 레포나 대화의 프로젝트명만으로 연결을 정하지 않는다.
- 과거 기록은 프로젝트명이나 주제어로 `search`해서 찾고 결과의 출처나 ID를 함께 제시한다.
- 프로젝트 상태 갱신은 `project_update`, 여러 프로젝트의 최신 상태 확인은 `overview`를 사용한다.
- `project_update` 결과의 `sync`도 확인한다. 사용자가 기억 폴더 동기화나 push 재시도를 요청하면 `sync`를 사용하고 결과를 알린다.

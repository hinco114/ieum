# 이음

이음은 Codex, Claude Code, Antigravity CLI가 같은 로컬 기억 폴더를 공유하게 해 주는 플러그인입니다. 한 세션에서 남긴 결정, 기술 메모, 프로젝트 상태를 다른 세션에서 찾아 이어서 작업할 수 있습니다.

## 플러그인 설치

Python 3.9 이상, Node.js 18 이상, 이 저장소의 로컬 사본이 필요합니다. 저장소 최상위 폴더에서 사용하는 에이전트에 맞는 설치 명령을 실행합니다.

### Codex

```sh
codex plugin marketplace add "$PWD"
codex plugin add ieum@ieum
```

### Claude Code

```sh
claude plugin marketplace add "$PWD"
claude plugin install ieum@ieum
```

### Antigravity CLI

```sh
agy plugin install "$PWD/plugins/ieum"
```

### 처음 설정

설치 후 새 세션에서 “이음 설정해 줘”라고 요청하고 기억을 저장할 폴더의 절대 경로를 알려줍니다. 같은 컴퓨터의 세 에이전트가 이 설정을 공유합니다.

## 플러그인이 하는 일

- **기억 저장** — AI가 요청받은 내용을 기록하고, 출처가 있으면 함께 남깁니다. 사용자가 프로젝트를 지정하면 그 프로젝트에 연결합니다. 그 밖에는 기억이 적용되는 범위를 AI가 판단합니다. 특정 프로젝트의 설정이나 결정은 해당 프로젝트에 연결하고, 여러 프로젝트에 쓸 수 있는 기술 지식이나 범위가 불분명한 내용은 일반 기억으로 저장합니다.
- **기억 검색** — 저장된 기억과 기존 위키를 함께 검색합니다. 첫 설정이나 기존 설정의 첫 검색에서 로컬 검색 모델(약 735MB)을 내려받아 색인을 준비합니다. 준비 중에는 기본 키워드 검색을 제공하며, 준비가 끝나면 한국어 형태소 검색과 의미 검색을 결합합니다.
- **프로젝트 상태 조회** — 프로젝트별로 진행 상태를 기록하고, 각 프로젝트에 마지막으로 남긴 상태를 모아 보여줍니다.

## 저장 위치와 Git 동기화

기억은 지정한 폴더의 `memory/ieum/`에 저장합니다. 기존 `wiki/`는 읽기 전용 검색 자료로 사용합니다.

기억 폴더가 Git 작업 트리에 있으면, 이음은 기억을 저장하거나 프로젝트 상태를 갱신할 때 `memory/ieum/`의 변경을 커밋합니다. 원격이 설정되어 있으면 현재 브랜치의 기본 설정에 따라 푸시합니다. 원격에 새 커밋이 있을 때는 Git 2.38 이상에서 충돌 여부를 확인하고, 병합할 수 있으면 반영한 뒤 푸시를 다시 시도합니다. 푸시가 실패하면 상태를 알려주고 다음 저장 때 다시 시도합니다.

제품의 전체 목표와 설계는 [제품 명세](SPEC.md)를 참고하세요.
